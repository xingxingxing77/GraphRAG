## 1. 效果构成（源码逆向结论）

参考实现的粒子球为**单 canvas、三层粒子、手写 3D 数学**，无任何库依赖：

| 层 | 数量 | 构成 |
|---|---|---|
| 球壳 | 2600 | 斐波那契球面分布（黄金角 `2.399963229728653`），`y = sign(u)·|u|^0.6` 极点加密；叠加微幅"卷曲闪烁" |
| 赤道波形带 | 1900 | 纬度 = 基准带内随机 + 三层正弦叠加波逐帧调制，形成绕球流动的亮带 |
| 环境散点 | 90 | 球外 2D 漂浮微粒，闪烁 + 慢漂，距球心 < 1.2R 不绘制、边界带软淡出 |

**3D 管线**（每帧每粒子）：绕 Y 轴自旋（0.00008 rad/ms）→ 固定 X 轴倾斜（0.32）→ 透视投影 `scale = CAM/(CAM+z)`（CAM = 3R）→ 深度决定尺寸与透明度（正面粒子显著更亮更大）。

**鼠标交互（真 3D 位移场）**：光标坐标 lerp（0.07，延迟跟手）→ 映射到球面正面半球（`z=-√(1-r²)`）→ 逆旋转回模型空间 → 对半径 0.32 内粒子施加 `(R-dist)·k` 推力 → 速度累积（回弹 0.0025 / 阻尼 0.95）→ 粒子被推开、悬浮漂移、缓慢归位。监听挂 `document` 级（canvas `pointer-events:none`），支持触屏。

**渲染细节**：粒子用 `fillRect` 方块绘制；`globalCompositeOperation='lighter'` 叠加发光；DPR 适配；canvas 尺寸为可见球的 180%（防止被推粒子在位图边缘裁剪）；容器 `mix-blend-mode: screen`。

## 3. 算法规格（1:1 常量表，实现须与下表一致）

| 常量 | 值 | 语义 |
|---|---|---|
| `SHELL_COUNT` | 2600（窄屏 1400） | 球壳粒子数 |
| `WAVE_COUNT` | 1900（窄屏 1000） | 波形带粒子数 |
| `STRAY_COUNT` | 90（窄屏 50） | 环境散点数 |
| `ROT_SPEED` | 0.00008 | 自旋角速度（rad/ms） |
| `TILT` | 0.32 | X 轴固定倾角（rad） |
| `WAVE_BAND` | 0.095 | 波形带纬度半宽 |
| `WAVE_LAT` | -0.5 | 波形带中心纬度偏移 |
| `WAVE_AMP` | 0.62 | 波形振幅系数 |
| `SHELL_SHIMMER` | 0.02 | 球壳闪烁幅度 |
| `FLOW_SPEED` | 0.0009 | 波形时间演化速度 |
| `STRAY_DRIFT` | 0.05 | 散点漂速（px/frame） |
| `STRAY_EXCL` | 1.2 | 球体避让半径（×R） |
| `MOUSE_R` | 0.32 | 光标影响半径（单位球空间） |
| `PUSH_K` | 0.016 | 推力系数 |
| `RETURN` | 0.0025 | 位移回弹系数 |
| `DAMP` | 0.95 | 速度阻尼 |
| `MOUSE_LERP` | 0.07 | 光标跟随插值 |
| `RADIUS` | `min(W,H)·0.255` | 球半径（canvas 内坐标） |

**波形函数**（球壳闪烁与波形带共用）：

```
wave(φ, t) = sin(6φ + t)·0.5 + sin(11φ + 1.7t)·0.3 + sin(3φ − 0.6t)·0.2
```

**每帧流程**：光标 lerp → 光标逆旋转入模型空间（`mlx,mly,mlz`）→ 清屏 → `lighter` 模式 → 逐粒子：算 home 位置（壳/带）→ 3D 推力累积 → 回弹+阻尼 → 位移合成 → 旋转+投影 → 按深度定 size/alpha → `fillRect` → 散点漂移闪烁绘制 → 恢复 `source-over` → rAF。

**球心锚定**：`positionOrb()` 沿 `offsetTop` 链（忽略 transform，避免入场动画拖拽球体）求锚点相对定位容器中心，加球高 38% 下移写入容器 `top`；在 resize / load / `fonts.ready` / 300·900·1600ms 兜底时重算。

## 4. 降级与可访问性

| 场景 | 行为 |
|---|---|
| `prefers-reduced-motion: reduce` | 仅渲染单帧静帧（无 rAF 循环、无交互位移） |
| 窄屏 `min(vw,vh) < 700` | 三层粒子数降档（§3 表括号值） |
| 页签不可见 | rAF 由浏览器自动暂停，无需额外处理 |
| HiDPI | canvas 物理尺寸 × `devicePixelRatio`，逻辑坐标不变 |

## 5. 登录/注册行为契约

- **登录**：沿用原页逻辑——`authStore.login({ grant_type: "password", username, password })`（02 §3.1 POST /auth/token），成功 `navigate("/chat")`；失败提示 `凭证错误，请重试（AUTH_400_BAD_CREDENTIALS）`。请求期间按钮禁用 + "登录中…"。
- **注册**：前端校验（必填 / 密码 ≥8 位 / 两次一致）→ 通过后提示"注册功能即将上线，敬请期待"。**不调用任何端点**；后端注册接口（02 契约扩展）就绪后仅替换 `onRegisterSubmit` 的提示段为真实调用，UI 不再变动。
- **Tab 切换**：登录/注册 pill 双 Tab；卡片脚部白色辉光按钮随 Tab 切换文案与所属 form（`form` 属性关联）。
