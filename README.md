## 快速开始（最小可跑）

```bash
docker compose up -d                 # 起 app:8000 / langgraph-server:8001 / 五存储 / ollama
curl http://localhost:8000/ready     # 全绿后开工
cd rag-web && pnpm i && pnpm dev     # 前端 :5173（详见 06 §1）
```
